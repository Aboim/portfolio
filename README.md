# Portfolio Pessoal

Site estatico single-page para showcase dos projectos pessoais.

## Stack

- HTML + CSS + JavaScript (vanilla, zero dependencias)
- Fonte: Outfit (Google Fonts)
- Icones: emoji nativos

## Funcionalidades

- Apresentacao pessoal com links (GitHub, LinkedIn)
- Grid de projectos com descricao, stack, status
- Links para cada projecto
- Tema escuro premium
- Responsivo (desktop, tablet, mobile)
- Animacoes suaves (CSS transitions)

## Uso

Abrir `index.html` no browser. Sem instalacao.

## Deploy

Basta copiar a pasta para qualquer servidor estatico (GitHub Pages, Netlify, Vercel).
